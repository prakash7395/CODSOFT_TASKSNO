# CodSoft Web Development Internship

This repository contains the web development projects I completed during my CodSoft Web Development Internship.

## Projects

### Task 1 – Personal Portfolio

A responsive personal portfolio website created using HTML and CSS.

### Task 2 – Landing Page

A responsive landing page designed using HTML and CSS with a clean and modern layout.

### Task 3 – Calculator

A functional calculator built using HTML, CSS, and JavaScript.

### Task 4 – Job Board

A responsive front-end job board website developed using HTML, CSS, and JavaScript.

Features include:

- Job search
- Job listings
- Job details
- Job application form
- Resume selection
- Candidate dashboard
- Employer dashboard
- Job posting form
- Login interface
- Responsive design

### Task 5 – Project Management Tool

A full-stack project management tool built using React, Node.js, Express.js, and MongoDB.

Features include:

- Create projects
- Assign tasks
- Set deadlines
- Track task progress
- Update task status
- Delete projects
